# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, welcome newcomers, accept feedback gracefully, and focus on what is best for the people who use this project. Harassment, insults, personal attacks and publishing other people's private information are not accepted, in issues, pull requests, Discussions or anywhere else this project is represented.

## Reporting

If someone's behaviour is not okay, tell the maintainer (mothannakhzaleh on GitHub) privately, or use GitHub's **Report content** option on the comment. Reports are handled in confidence. The maintainer may remove comments, lock threads or block people who break this code of conduct.
